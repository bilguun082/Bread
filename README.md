# 🥖 Гарын Сайн Талх - Хүргэлт & Тооцооны Систем (B2B Bread Delivery & Store AR)

Хөрөнгөний талх үйлдвэрлэн олон дэлгүүрт хүргэлт хийдэг ээжид зориулсан **Mobile-First, 5-Second Quick Entry, 58mm Bluetooth Mini Thermal Receipt & Store AR Reconciliation** веб аппликейшн.

Машиндаа нэг гараараа бариад ердөө 5 секундэд тухайн дэлгүүрийн хүргэлт, өчигдрийн буцаалт, төлбөрийн хэлбэр (бэлэн/данс/зээл)-ийг бүртгэж, 58mm кассын принтерээр газар дээр нь баримт хэвлэн өгөхөд зориулагдсан.

---

## 🚀 Хэрхэн ажиллуулах вэ? (Quickstart)

### 1. Шаардлагатай орчин
- Node.js 18+ (эсвэл Bun)
- npm / yarn / pnpm

### 2. Сангуудыг суулгах
```bash
npm install
```

### 3. Өгөгдлийн санг үүсгэх ба жишээ дата оруулах
Энэ систем нь үүлэн **MongoDB Atlas** өгөгдлийн баазтай холбогдсон тул ээж хаанаас ч хамаагүй гар утасныхаа дата (4G/LTE)-аар хүргэлтээ шууд үүлэн бааз руу хадгалах боломжтой:
```bash
# Prisma Client үүсгэж MongoDB Atlas дээр коллекц, индексүүдийг үүсгэх
npm run prisma:push

# 3 төрлийн хөрөнгөний талх болон анхны 5 дэлгүүрийн өгөгдлийг оруулах (Seed)
npm run seed
```

Код нь UI дүрслэл болон Бизнес логикийг бүрэн заагласан (Container/Presentational pattern) бүтэцтэй:

```plaintext
src/
├── app/                  # Next.js App Router хуудсууд ба REST API endpoints
│   ├── api/              # Хүргэлт, дэлгүүр, ачилт, тайлангийн API routes
│   │   ├── products/     # Бүтээгдэхүүний үнэ, өртөг
│   │   ├── stores/       # Дэлгүүрүүдийн CRUD, авлага
│   │   ├── daily-run/    # Өдрийн ачилт ба машины талхны үлдэгдэл
│   │   ├── delivery/     # 5 секундийн хүргэлт, гүйлгээний тооцоолол
│   │   ├── reports/      # Өдрийн хаалт (daily) ба сарын P&L (monthly)
│   │   └── expenses/     # Гурил, түлш, уут савны зардал
│   ├── stores/           # Дэлгүүрүүд ба өр авлагын хуудас
│   ├── reports/          # Өдрийн хаалтын тулгалт ба сарын ашгийн хуудас
│   ├── layout.tsx        # Гар утсанд зориулсан ерөнхий бүтэц, навигаци
│   └── page.tsx          # Өдрийн хүргэлтийн нүүр хуудас
├── components/
│   ├── common/           # Дахин ашиглагдах суурь UI элементүүд (Button, Stepper, Modal, Input, Badge, Card)
│   └── features/         # Бизнес логикийн мобайл UI (DeliveryModal, RouteStoreItem, TruckInventoryHeader, ReceiptModal, DailyReconciliationCard)
├── hooks/                # Бизнес логик, төлөв хариуцсан Custom hooks (useDailyRun, useStores, useReceiptPrinter)
├── services/             # Сервер ба төхөөрөмжтэй харьцах client services (apiClient, deliveryService, storeService, reportService, printerService, db)
├── types/                # Бүх өгөгдлийн strict TypeScript interface тодорхойлолтууд
└── utils/                # Цэвэр функцууд (deliveryMath, escposGenerator, currencyFormatter, dateUtils)
```

## 💡 Системийн үндсэн боломжууд (MVP Feature Highlights)

### 1. 🚚 Өдрийн хүргэлт (Mobile Delivery Run)
- **Машинд үлдсэн талхны индикатор:** Машинд ачсан тооноос хүргэсэн тоог автоматаар хасч, 1-р гурил, Бүхэл үр, Багет тус бүрээр үлдсэн тоог үргэлж тод харуулна.
- **Маршрутын жагсаалт:** Дэлгүүрүүдийн нэрс, утас руу шууд залгах товч, өртэй эсэх нь ногоон/улаан шошготой харагдана.
- **5 секундийн Хүргэлтийн Цонх:**
  - Өмнөх өрийн үлдэгдэл тод харагдана.
  - 3 талх тус бүр дээр том хэмжээтэй `[-]` `[ 5 ]` `[+]` болон `буцаалт` тоо хасах хэсэг.
  - Төлбөр хэсэгт 1 товшилтоор хуваарилах: `[ Бүгд бэлнээр ]`, `[ Бүгд дансаар ]`, `[ Зээл / Өр ]` хурдан товчнууд.

### 2. 🖨️ 58mm Bluetooth Mini Printer & Web Print
- **Web Bluetooth ESC/POS Direct:** Утаснаасаа шууд ойролцоох жижиг Bluetooth кассын принтерт холбогдож 1 секундэд хэвлэнэ.
- **58mm Thermal Print CSS:** iPhone Safari болон бусад стандарт хөтөч дээр AirPrint / Системийн хэвлэх цонхоор 58мм цаасан дээр гарын үсэг зурах зураастай баримт хэвлэнэ.

### 3. 🏬 Дэлгүүрүүд ба Тооцоо (Store AR / Balance)
- Нийт авлага (дэлгүүрүүдийн өр)-ийн нэгдсэн дүн.
- Дэлгүүр бүрийн хүргэлт, буцаалт, өр төлөлтийн дэлгэрэнгүй хуулга, өнгөрсөн чекийг дахин хэвлэх.
- Шинэ дэлгүүр бүртгэх.

### 4. 📊 Өдрийн хаалт ба Сарын ашиг (Reconciliation & P&L)
- **Талхны тооцоо:** `Ачсан = Хүргэсэн + Буцаалт + Үлдсэн` зөрүү хянах.
- **Мөнгөний тооцоо:**
  - Түрийвчинд тоолох бэлэн мөнгөний дүн.
  - Банкны хуулгаар тулгах дансны орлого.
  - Шинээр үүссэн өр (зээл).
- **Сарын P&L:**
  - Борлуулалт - Өртөг (COGS) = Бохир ашиг.
  - Зардал (Гурил, түлш, уут, тогоо бүртгэх).
  - Энэ сарын **ЦЭВЭР АШИГ** автоматаар бодогдоно.
